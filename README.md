# Hermes Bot Mode · Tài liệu (tiếng Việt)

Tài liệu kiến thức tiếng Việt về **Hermes Bot Mode** — tính năng biến các agent profiles của [Hermes Agent](https://github.com/NousResearch/hermes-agent) thành một đội bot riêng biệt (chat, avatar, lịch, bot-to-bot messaging).

Trang docs: **https://masuphan.github.io/hermes-bot-mode-docs/**

## Ai nên đọc

| Nhánh | Đối tượng |
|---|---|
| [`business/`](business/) | Người đọc business — hiểu giá trị, use case, bắt đầu nhanh, không cần code |
| [`dev/`](dev/) | Developer — hiểu kiến trúc, cài đặt, mở rộng |

## Nguồn

Nội dung dựa trên repo mã nguồn mở [`NousResearch/Hermes-Bot-Mode`](https://github.com/NousResearch/Hermes-Bot-Mode) (đã archive 17/08/2026, nay tích hợp sẵn trong Hermes Desktop).

## Chạy local

```bash
bundle install
bundle exec jekyll serve
```

Trang chạy tại `http://localhost:4000`.
